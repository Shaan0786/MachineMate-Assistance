# 🛠️ MachineMate Assistant

**MachineMate Assistant** is a smart, multilingual, and offline-capable QR-based safety and operational guidance tool designed specifically for factory floors. It bridges communication gaps and ensures instant access to Standard Operating Procedures (SOPs) and safety protocols.

---

## 🚀 Key Features

* **🌐 Multilingual Support:** Real-time voice and visual instructions available in **Hindi, Tamil, Telugu, and English**.
* **📱 Responsive Views:** Optimized layouts tailored for both factory floor mobile devices (phones) and supervisor control centers (laptops).
* **📶 Offline-Capable:** Designed to function seamlessly even in remote or low-connectivity industrial zones using local storage and robust caching.
* **📷 QR Code Scanning:** Instant scanning of machine codes to pull up specific operating guidelines and safety checklists.
* **🚨 Emergency SOS System:** Quick-access emergency trigger to instantly alert supervisors and log critical incidents.

---

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Styling & UI:** Tailwind CSS / Modern CSS components
* **Icons & Assets:** Lucide React icons
